# Three.js 3D粒子系统 - 手势控制使用指南

## 项目简介
这是一个基于Three.js的实时3D粒子系统，支持通过摄像头手势控制，提供多种模型选择和颜色自定义功能。

## 手势操作指南

### 🎯 基础操作步骤

1. **准备工作**
   - 确保摄像头已开启并对准您的手部
   - 保持手部在摄像头视野中央（右上角小窗口可见）
   - 建议手部与摄像头距离：10-20厘米

2. **手势校准**
   - 首次将手放在摄像头前时，系统会自动进行校准
   - 校准完成后，屏幕会显示："🎯 校准完成！请张合手指控制缩放"
   - 校准过程仅需1-2秒

3. **缩放控制**
   - **放大**：将食指和拇指张开（形成"OK"手势的展开状态）
   - **缩小**：将食指和拇指靠近（形成"OK"手势的闭合状态）
   - **保持不变**：保持手指间距离稳定

4. **停止控制**
   - 将手移开摄像头视野，系统会自动停止控制
   - 重新放置手时需要再次校准

### 💡 优化后的控制特性

- **更高灵敏度**：优化了检测算法，更容易检测到手部动作
- **更大缩放范围**：支持0.3-3.0倍缩放（原0.5-2.0倍）
- **更快响应速度**：增加了平滑过渡系数，动作反馈更及时
- **直观状态提示**：实时显示当前缩放百分比
- **更稳定检测**：降低了置信度阈值，减少手部丢失情况

### 📱 最佳实践

1. **手部姿势**
   - 保持手掌朝向摄像头
   - 手指自然伸展，避免过度弯曲
   - 尽量在明亮环境下使用

2. **控制技巧**
   - 小幅度张合手指可实现精细调节
   - 大幅度张合可快速改变缩放比例
   - 保持手部稳定，避免频繁抖动

3. **常见问题解决**
   - **无法检测到手**：调整手部位置，确保在摄像头中央
   - **控制不灵敏**：靠近或远离摄像头，重新校准
   - **抖动严重**：保持手部稳定，尝试在更明亮环境下使用

## 功能特性

### 🎨 模型选择
- **爱心**：实心爱心形状，粉色与白色粒子组成
- **花朵**：花瓣形状粒子系统
- **土星**：环形行星形状
- **烟花**：爆炸效果粒子系统

### 🌈 颜色自定义
- **主色调**：粒子的主要颜色
- **辅助色**：粒子的点缀颜色

### ⚙️ 其他控制
- **自动旋转**：开启/关闭粒子系统自动旋转
- **全屏模式**：切换全屏显示
- **状态提示**：实时显示当前操作状态

## 启动方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器运行：
   ```bash
   # 使用Python 3
   python -m http.server 8000
   
   # 然后在浏览器中访问 http://localhost:8000
   ```

## 系统要求

- 现代浏览器（Chrome/Firefox/Safari/Edge）
- 支持WebGL的显卡
- 内置或外接摄像头
- 稳定的网络连接（首次加载需要下载AI模型）
