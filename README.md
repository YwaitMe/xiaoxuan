# 豪华3D粒子树 - 手势控制

一个基于Three.js和MediaPipe的交互式3D粒子系统，支持手势控制和图像上传功能。
在线演示：https://ywaitme.github.io/xiaoxuan/

## 手势操作指南

### 基础操作
- **张开手掌**：进入分散模式 - 粒子会散开到随机位置
- **握拳**：进入树形模式 - 粒子会形成树形结构
- **捏合食指和拇指**：进入聚焦模式 - 粒子会向一个随机点聚集

### 最佳实践
- 确保在良好的光线条件下使用手势控制
- 将手放在距离摄像头30-60厘米的位置
- 保持手的姿势稳定1-2秒以确保正确识别
- 可以同时使用键盘快捷键控制场景（WASD移动，空格重置）

## 功能特性

### 模型选择
- **树形模式**：粒子呈现类似树的结构，具有层次化的分支
- **分散模式**：粒子随机分布在空间中
- **聚焦模式**：粒子向一个点聚集，形成视觉焦点

### 颜色自定义
- 支持通过图像上传自定义粒子颜色
- 内置多种预设颜色主题
- 可以根据粒子位置动态调整颜色

## 启动方法

1. 确保您的设备已连接摄像头
2. 打开 `index.html` 文件
3. 允许浏览器访问摄像头
4. 使用手势控制粒子系统

## 系统要求

- 现代浏览器（支持WebGL和WebRTC）
- 具有摄像头的设备
- 支持GPU加速的图形卡
