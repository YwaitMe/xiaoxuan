# 动物测试网页

这是一个有趣的动物测试网页，用户可以通过长按按钮获取随机的动物测试结果。

## 功能特点

### 🎯 核心功能
- **长按测试**：长按主按钮2秒，系统会随机生成15种动物结果
- **多维度分析**：测试结果从15个不同维度展示你的动物特质
- **随机算法**：使用加权随机算法，确保结果的随机性和多样性

### 🎨 界面设计
- **深色/浅色模式**：支持两种主题模式切换，适应不同光线环境
- **响应式布局**：适配各种屏幕尺寸，从手机到桌面设备
- **现代UI设计**：简洁美观的界面，流畅的动画效果

### 💾 数据管理
- **本地存储**：测试结果自动保存到浏览器本地存储，刷新页面后不会丢失
- **数据持久化**：支持保存和加载测试历史记录

## 如何使用

### 本地运行
1. 克隆或下载仓库文件
2. 在浏览器中打开 `index.html` 文件
3. 长按主按钮开始测试
